# متجر D — Matjar D (Store D) 🛍️

تطبيق أندرويد لمتجر إلكترونيات محلي (وهران) على شكل **تطبيقين** يتشاركان نفس الخلفية (Supabase):

- **`:customer`** — تطبيق الزبون: الكتالوج، السلة، الطلب مع الدفع عند الاستلام، تتبع الطلب. (`com.matjard.customer`)
- **`:admin`** — تطبيق المسؤول: لوحة تحكم كاملة لإدارة المنتجات، الأقسام، الإعلانات، الطلبات وإعدادات المتجر — كل تعديل ينعكس فوراً على تطبيق الزبون. (`com.matjard.admin`)
- **`:matjar-core`** — مكتبة Kotlin مشتركة (نماذج البيانات + الوصول إلى Supabase PostgREST/Auth/Storage).
- **`:app`** — تطبيق AI EVO الأصلي (لم يتغير).

**العربية والفرنسية** في كل الواجهات (تبديل داخل التطبيق + RTL كامل).

📚 **دليل الإعداد والتشغيل والنشر: [docs/MATJAR_D.md](docs/MATJAR_D.md)** — يشمل مشروع Supabase الجاهز، خطوة إنشاء حساب المسؤول، أوامر البناء، والنشر على Google Play.

```bash
./gradlew :customer:assembleDebug :admin:assembleDebug
```
